# CodeQL alert 258 review

Reviewed on 25 September 2026 against bundled WooCommerce 11.0.1 and jQuery 3.7.1. This record concerns one reported dataflow, not the security of the entire plugin.

[Alert 258](https://github.com/MatthiasReinholz/wp-core-base/security/code-scanning/258), rule `js/xss-through-dom`, was dismissed as a false positive after source, SARIF and isolated browser review. No vendor patch or scanner-wide exclusion was introduced.

## Source and sink

In `updateLegacyPreview`, the receiver is selected with `.find('img').first()`. The flagged value comes from its `data-placeholder-src` attribute and is written to the fixed `src` attribute through jQuery `.attr()`. The reviewed jQuery implementation calls `setAttribute`; this path does not parse HTML or write a script-capable element. The normal server-rendered URL is escaped and cached from the same image.

The method is byte-identical in upstream WooCommerce 11.1.2, with SHA-256 `c44cd6e01748db1bbb50d832eda7c98df272e8bed71a56c8f29a438a1a63dd16`.

- [WooCommerce method](https://github.com/woocommerce/woocommerce/blob/11.1.2/plugins/woocommerce/client/legacy/js/admin/variation-gallery.js#L884-L905)
- [jQuery attribute implementation](https://github.com/jquery/jquery/blob/3.7.1/src/attributes/attr.js)
- [SVG secure image processing](https://svgwg.org/svg2-draft/conform.html#secure-animated-mode)
- [CodeQL rule documentation](https://codeql.github.com/codeql-query-help/javascript/js-xss-through-dom/)

## Dynamic verification

An isolated Chromium 153.0.8010.12 test loaded the actual bundled method and jQuery. It assigned attacker-controlled HTML, quote-breakout, `javascript:`, script-bearing SVG data and HTML data URLs to the source attribute, then called the alerted branch. All five cases preserved the attribute as data, introduced no nodes or event-handler attributes, and executed no script. The SVG decoded successfully without executing its scripts. A separate `innerHTML` positive control executed once.

This was an isolated test, not a complete authenticated wp-admin session. Firefox and WebKit were not verified because their installed test runtimes failed initialization. Changes to element selection, the attribute name, jQuery hooks, or downstream interpretation of the value require a fresh review. The source/sink distinction and SVG processing rules provide evidence beyond the single tested browser.

## Separate dependency maintenance

WooCommerce 11.1.1 and 11.1.2 contain security fixes unrelated to this assignment. The [11.1.2 announcement](https://developer.woocommerce.com/2026/09/22/woocommerce-11-1-2/) describes email-review validation and a PHP variation-gallery recursion fix. Neither fixes this reported image-attribute flow.

WooCommerce 11.1.2 declares WordPress 7.0 as its minimum, whereas the v1.5.0 optional starter baseline used WordPress 6.9.9. The coordinated core/plugin migration is included in [v1.6.0](../releases/1.6.0.md), with seeded database upgrade and rollback checks. A green static check or dismissed alert is not evidence that a newer plugin is compatible with older core. Framework staging checks discovered and declared plugin minimum WordPress requirements against the actual staged managed core. Projects supplying core externally must verify compatibility in their deployment environment.
