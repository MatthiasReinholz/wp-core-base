# wp-core-base 1.4.7

## Summary

This is the `patch` framework release from `v1.4.6` to `v1.4.7` for `wp-core-base`.

It publishes the current validated framework state for downstream adoption and framework self-update PRs, including refreshed action pins, bounded reconciliation jobs, and the reviewed dependency baseline.

## Downstream Impact

Downstream repositories pinned to an older `wp-core-base` release can update to `v1.4.7` through `framework-sync` or by vendoring the published snapshot manually.

Adoption refreshes framework-managed GitHub workflow action pins and adds a 30-minute bound to dependency reconciliation sync jobs. It also carries the reviewed bundled updates listed below; project-owned runtime code is unaffected.

## Migration Notes

No configuration migration is required for `v1.4.7`.

If your downstream repository has locally customized scaffolded workflow files, review upstream workflow diffs manually before adopting this release.

## Downstream Workflow Changes

The scaffolded GitHub reconciliation workflow now limits its `sync` job to 30 minutes so a stalled external dependency source cannot consume an unbounded runner. Framework-managed GitHub workflows also use the reviewed `actions/checkout` 7.0.1 and `shivammathur/setup-php` 2.37.2 commit pins. No permissions or GitLab pipeline behavior changed.

## Required Downstream Actions

Review the generated framework-update PR and run `framework-sync --check-only --fail-on-skipped-managed-files` before adoption. Downstreams without customized framework-managed files can then merge the generated update normally. Reconcile intentional workflow customizations manually if strict preflight reports skipped files.

## Bundled Baseline

- WordPress core: `7.1`
- WooCommerce `11.0.1`
- Jetpack `16.1.2`
- Contact Form 7 `6.1.7`
- Redirection `5.10.0`

## Operational Notes

The published framework asset for this release is `wp-core-base-vendor-snapshot.zip`.

Normal release flow: run `prepare-wp-core-base-release`, review and merge `release/v1.4.7`, then let `finalize-wp-core-base-release` create the tag and publish the authoritative framework release artifact.
