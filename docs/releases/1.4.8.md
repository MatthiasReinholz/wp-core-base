# wp-core-base 1.4.8

## Summary

This is the `patch` framework release from `v1.4.7` to `v1.4.8` for `wp-core-base`.

It publishes the reviewed WooCommerce 11.0.1 dependency baseline for downstream adoption and framework self-update PRs.

## Downstream Impact

Downstream repositories pinned to an older `wp-core-base` release can update to `v1.4.8` through `framework-sync` or by vendoring the published snapshot manually.

Adoption updates the bundled WooCommerce baseline from 10.8.1 to 11.0.1. Project-owned runtime code and framework-managed workflows are unchanged.

## Migration Notes

No special migration steps are expected by default for `v1.4.8`.

If your downstream repository has locally customized scaffolded workflow files, review upstream workflow diffs manually before adopting this release.

## Downstream Workflow Changes

This release does not change framework-managed downstream workflows, pipeline templates, required permissions, or framework-sync behavior.

## Required Downstream Actions

Review the generated framework-update PR and run `framework-sync --check-only --fail-on-skipped-managed-files` before adoption. Downstreams already carrying WooCommerce 11.0.1 should see no WooCommerce runtime change.

## Bundled Baseline

- WordPress core: `7.1`
- WooCommerce `11.0.1`
- Jetpack `16.1.2`
- Contact Form 7 `6.1.7`
- Redirection `5.10.0`

## Operational Notes

The published framework asset for this release is `wp-core-base-vendor-snapshot.zip`.

Normal release flow: run `prepare-wp-core-base-release`, review and merge `release/v1.4.8`, then let `finalize-wp-core-base-release` create the tag and publish the authoritative framework release artifact.
