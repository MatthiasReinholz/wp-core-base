# wp-core-base 1.6.7

## Summary

This release updates the optional starter baseline to official Contact Form 7
6.2.1 and WooCommerce 11.2.1. Managed runtime files retain their verified upstream
bytes after the existing sanitation policy; no third-party source patch is added.
Published release notes, tags and signed artifacts for earlier versions remain
unchanged.

## Downstream Impact

The optional starter now requires PHP 8.3 or newer because Contact Form 7 6.2.1
requires that version and WordPress 7.1. The bundled WordPress 7.1.3 meets the core
requirement. Framework CLI compatibility with PHP 8.1 remains separately tested;
it does not lower plugin runtime requirements.

WooCommerce 11.2.1 restores normal classic-checkout request serialization and
updates its shipped frontend bundles. The patch introduces no new database
migration callbacks or template changes relative to 11.2.0. Existing site's
checkout, payment and integration behavior still requires downstream acceptance.

## Migration Notes

Framework sync updates tooling and recorded baseline metadata, not downstream
WordPress core, plugins, PHP deployments or databases. The signed tooling ZIP
excludes the optional runtime starter. Existing consumers do not acquire the
new plugin runtime merely by adopting this framework release.

Projects adopting this starter or independently upgrading these plugins must
meet their runtime requirements and use the [baseline upgrade and rollback
procedure](../baseline-upgrades.md). Retain a verified database/runtime backup;
a runtime rollback does not reverse prior WooCommerce database changes.

## Downstream Workflow Changes

No framework-managed downstream workflow or pipeline template changes are
included. The upstream source repository's two-profile runtime smoke and seeded
upgrade matrix replaces PHP 8.1 with PHP 8.3, retaining PHP 8.4 and 8.5. Its PHP
8.1 framework CLI compatibility lane remains unchanged. Required upstream smoke
contexts must name the supported runtime; no check is waived.

## Required Downstream Actions

Adopt the signed release through the normal reviewed `framework-sync` process,
run downstream validation, and preserve locally customized files. Use
`framework-sync --check-only --fail-on-skipped-managed-files --json` when managed
customizations must block adoption. Separately qualify any intended runtime
plugin update, including form submission without real mail delivery and store
checkout/payment behavior; framework installation is not that qualification.

## Bundled Baseline

- WordPress core: `7.1.3`
- WooCommerce `11.2.1`
- Jetpack `16.3`
- Contact Form 7 `6.2.1`
- Redirection `5.10.1`

## Operational Notes

The authoritative artifact remains `wp-core-base-vendor-snapshot.zip`, its
SHA-256 sidecar and detached signature. Normal exact-revision validation,
security review and publication gates remain required. Both profiles are covered
by real fresh-install and seeded HPOS/legacy-order upgrade and paired rollback
fixtures. Those synthetic checks do not certify production data or external
payment, mail, Jetpack or form-provider integrations. The recorded WordPress
baseline security findings remain open; this release does not declare the
runtime security-cleared.
