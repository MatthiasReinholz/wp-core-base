# wp-core-base 1.4.5

## Summary

- Fixed signed framework self-updates by retaining the published checksum and
  signature sidecar filenames in the per-operation temporary directory.
- Added a regression contract for the signature-bound sidecar filenames.

## Downstream Impact

- Downstreams can now verify and adopt signed framework releases through
  `framework-sync`; v1.4.4 could be published and verified by the release
  pipeline but could not be consumed by the self-update command.
- This release also contains the managed-PR branch lifecycle cleanup introduced
  in v1.4.4.

## Migration Notes

- No application or content migration is required.
- Adopt v1.4.5 instead of v1.4.4. Signature and checksum verification remain
  mandatory; no verification step has been weakened or bypassed.

## Downstream Workflow Changes

- The workflow changes documented for v1.4.4 are included: closed managed PRs
  receive a narrowly scoped branch-cleanup job while reconciliation remains
  merged-only.
- No additional workflow template changes are introduced by this follow-up fix.

## Required Downstream Actions

1. Update directly to v1.4.5 through the normal reviewed framework-update PR.
2. Reconcile customized `.github/workflows/wporg-updates-reconcile.yml` files
   manually to add the v1.4.4 cleanup job while preserving local runner, secret,
   timeout, and bootstrap choices.
3. Keep existing human or bot approval and merge policy. The cleanup job never
   approves or merges dependency PRs.

## Bundled Baseline

- WordPress core: `6.9.4`
- WooCommerce `10.7.0`
- Jetpack `15.7.1`
- Contact Form 7 `6.1.5`
- Redirection `5.7.5`

## Operational Notes

The published framework asset for this release is `wp-core-base-vendor-snapshot.zip`.

Normal release flow: run `prepare-wp-core-base-release`, review and merge `release/v1.4.5`, then let `finalize-wp-core-base-release` create the tag and publish the authoritative framework release artifact.
