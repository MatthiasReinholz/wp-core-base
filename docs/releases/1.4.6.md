# wp-core-base 1.4.6

## Summary

- Fixed generated dependency and WordPress core update branches so they keep
  framework baseline metadata, README facts, and release-note facts coherent
  with the updated payload and manifest.
- Added upstream-only synchronization with strict section matching, ambiguity
  checks, downstream isolation, and integration regression coverage.

## Downstream Impact

- Dependency and core PRs generated or refreshed by v1.4.6 now contain every
  public baseline file required by release verification.
- Vendored downstream `.wp-core-base/framework.php` locks remain pinned; the
  synchronizer runs only in the framework source repository.

## Migration Notes

No manifest, runtime, or application migration is required. Adopt v1.4.6 through
the normal reviewed framework-update PR before relying on refreshed dependency
or core update branches.

## Downstream Workflow Changes

No framework-managed workflow or pipeline template changes are included.

## Required Downstream Actions

1. Review and adopt the v1.4.6 framework-update PR.
2. Continue reviewing dependency and core PRs normally; this release fixes their
   generated contents but does not approve or merge them automatically.

## Bundled Baseline

- WordPress core: `6.9.4`
- WooCommerce `10.8.1`
- Jetpack `16.1.2`
- Contact Form 7 `6.1.7`
- Redirection `5.10.0`

## Operational Notes

The published framework asset for this release is `wp-core-base-vendor-snapshot.zip`.

Normal release flow: run `prepare-wp-core-base-release`, review and merge `release/v1.4.6`, then let `finalize-wp-core-base-release` create the tag and publish the authoritative framework release artifact.
